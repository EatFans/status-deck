# Dev Board Hardware

这里记录开发板验证阶段的硬件方案。

这个阶段优先使用现成 ESP32 开发板和常见模块，目标是快速验证 BLE 通信、屏幕显示、供电和交互方式。等功能稳定后，再把经过验证的连接关系整理到正式 PCB 工程里。
