# Hardware

这里放 Status Deck 的硬件资料。

硬件部分分成两个阶段管理：先用现成开发板和模块快速验证功能，再整理成可复刻的 PCB 工程。

## 目录

```text
hardware/
├── dev-board/       # 开发板和模块验证
└── pcb/             # 正式 PCB 工程
```

## 开发板验证阶段

`dev-board/` 用来记录早期买模块、飞线、面包板或洞洞板测试的信息，包括：

- ESP32 开发板选择
- 显示屏模块选择
- 供电方式
- 按键、旋钮、LED、蜂鸣器等交互模块
- 引脚分配
- 接线图
- 模块购买链接和替代型号
- 测试记录和已知问题

## PCB 阶段

`pcb/` 用来放后续正式硬件工程，包括：

- 原理图
- PCB 版图
- BOM
- Gerber
- 坐标文件
- 生产和焊接说明
- 外壳或结构配合说明
